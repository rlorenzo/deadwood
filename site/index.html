Deadwood

Find the dead code in your Rust workspace that rustc and Clippy miss.

It reads your source without compiling it, so there's no build to wait for and no nightly toolchain. The whole rust-lang/rust workspace takes seconds.

cargo install deadwood-rs

What rustc and Clippy don't report

The dead_code lint assumes a library's pub items are used by someone outside the crate. Inside a workspace that's often false, and that's where dead code piles up.

Run it in CI

Add the action to a workflow. Pin the full commit SHA of a release tag; the action builds Deadwood from that commit.

On an existing codebase, run deadwood check --write-baseline once and commit the file. After that, only new findings fail the build.

Workflow steps
- uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1
- uses: rlorenzo/deadwood-rs@65c159dcbf29ed50ee6f784467105f179716a76f # v1.0.1
  with:
    path: .   # workspace to analyze
